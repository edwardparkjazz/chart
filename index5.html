ECharts 로 옮기면서 달라진 것

렌더러를 직접 짜던 것을 ECharts 로 바꾸면서, 실서비스에 필요한 기능이 대부분 기본 제공으로 해결됩니다.

얻은 것

기본 제공으로 대체된 기능

  • dataZoom — 휠 확대·드래그 이동·하단 슬라이더
  • axisPointer link — 3개 그리드 크로스헤어 동기화
  • tooltip formatter — 지표 값 일괄 표시
  • markLine / markArea / markPoint — 지지선·구간·크로스 마커
  • 반응형 resize, 접근성, 모바일 터치 제스처

직접 해야 하는 것

ECharts 가 대신해 주지 않는 부분

  • 스케치 캡처 — 캔버스 레이어를 위에 얹어 직접 처리
  • 픽셀↔데이터 변환 — convertFromPixel / convertToPixel
  • 지표 계산 — ECharts 는 렌더만 함
  • 볼린저 밴드 채우기 — stack 트릭 필요
  • 3D — echarts-gl 로는 캔들 단면 절단이 어려워 three.js 유지

실서비스 관점

왜 ECharts 가 맞는 선택인가

  • 서버 ChartSpec → ECharts option 어댑터만 쓰면 됨
  • SSR(node-canvas)로 공유 이미지·리포트 PNG 생성 가능
  • 수작업 렌더러의 브라우저별 버그를 떠안지 않음
  • 나인메모스 기존 차트가 ECharts 라면 지표 옵션 재사용
